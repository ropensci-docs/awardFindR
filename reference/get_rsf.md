# Get Russell Sage foundation awards

Get Russell Sage foundation awards

## Usage

``` r
get_rsf(keyword, verbose = FALSE)
```

## Arguments

- keyword:

  Keyword to query, single string

- verbose:

  enable verbose HTTP messages. TRUE/FALSE, default: false

## Value

a data.frame

## Examples

``` r
if (FALSE) rsf <- get_rsf("ethnography") # \dontrun{}
```
