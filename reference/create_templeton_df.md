# Scrape the Templeton grants database from html to a data.frame

Scrape the Templeton grants database from html to a data.frame

## Usage

``` r
create_templeton_df(verbose = FALSE)
```

## Arguments

- verbose:

  enable verbose HTTP messages. TRUE/FALSE, default: false

## Value

A data.frame

## Examples

``` r
if (FALSE) templeton <- create_templeton_df() # \dontrun{}
```
